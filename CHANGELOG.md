# Changelog

All notable changes are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/); versions follow [SemVer](https://semver.org/) once 1.0 ships.

## [Unreleased]

## [0.4.0] - 2026-11-09

Real 3D models: glTF import, a Content Browser, and textures.

### Added
- Assets module (layer 1): glTF 2.0 importer for `.gltf` and `.glb` (meshes, node hierarchy with TRS or matrix, base colour factor and texture, computed normals), with bounds checks, URI path safety and size limits on untrusted files; PNG/JPEG decoding via vendored stb_image 2.30. 7 tests including a 3,000-case GLB fuzz test. ADR 0012.
- Renderer: vertex UVs, `upload_texture()` with mipmaps, one base colour texture per draw (white by default), `MeshInstance::texture`.
- `ModelLibrary`: content folder of models; imports, uploads and names primitives and textures (`asset:<path>#mesh<m>.<p>`, `#texture<t>`); spawns models as entity hierarchies; levels that name models load them on demand.
- Level format: optional `MeshInstance.texture` (schema and docs updated; files without it are unchanged).
- Editor: Content Browser panel (filter, refresh, double-click to add, drag into the viewport to place on the ground), Details shows mesh and texture names, picking uses model bounds; `--content DIR`.
- Runtime demo: `--content DIR`; plays levels that use models.
- Sample models (crate, torus, tree) generated by `tools/make_sample_content.py`, checked in CI and shipped as `Content/`; `samples/levels/model_garden.alevel`.

### Fixed
- The grid pipeline no longer declares a vertex attribute its shader does not read (validation performance warning).

## [0.3.0] - 2026-11-09

Levels can be saved and opened.

### Added
- Level files (`.alevel`): documented JSON format v1 (`docs/formats/level-v1.md`) with a JSON Schema checked in CI; save/load with type-checked, rollback-on-error loading; unknown or invalid component data preserved; step-wise migrations (`upgrade_level`); atomic file writes. ADR 0011.
- Foundation JSON parser and writer with depth/size limits, line/column errors and exact float round-trips; fuzz-tested.
- `SerializerRegistry` with per-module registration (world: Name, Transform; render: MeshInstance via `MeshRegistry` names; gameplay: Spin). `World::for_each_entity`.
- Gameplay module (layer 3) with the `Spin` component and system, shared by editor and runtime.
- Editor: New / Open / Open Recent / Save / Save As, built-in file browser, unsaved-changes prompt (also on window close), title and status bar show the level and `*`, open by command line or drag-and-drop, `--export-demo`.
- Runtime demo: `--level file.alevel` plays levels saved by the editor.
- `samples/levels/solar_system.alevel`, kept identical to the editor's export by a test; shipped in the Windows package.

### Fixed
- Editor shortcuts no longer fire while a dialog is open.
- Render tests keep the Mesa software driver loaded so sanitizer leak reports from the driver are attributed correctly (they could be mislabelled after the driver was unloaded, defeating the driver-only suppressions).

## [0.2.0] - 2026-11-09

Editor preview. Windows editor and demo published on GitHub Releases.

### Added
- Editor (`editor/`, `aether_editor`): docking UI with Viewport, Outliner, Details, Place Actors, Output Log and Stats; menus, toolbar, status bar; move/rotate/scale gizmos with snapping; click picking; fly/orbit/pan/zoom camera; undo/redo for edits, create, delete, duplicate and attach; play-in-editor with restore on Stop; dark theme with embedded Roboto font. 11 tests. ADR 0010.
- Renderer UI mode (scene in a viewport texture, correct sRGB for UI and scene), selection highlight, analytic anti-aliased ground grid. 2 new pixel tests.
- Math: `inverse`, `decompose`, Euler angle conversion, `transform_projective`. 3 tests.
- World: `Name` component. Foundation: `MemorySink::clear`.
- Vendored Dear ImGui 1.91.5 (docking), ImGuizmo and the Roboto font.
- CI smoke-tests the editor; the Windows package contains the editor, the demo and a quick-start guide.

### Changed
- Release packaging lives in `tools/package_windows.ps1` and runs on every CI build.

## [0.1.0] - 2026-11-09

First preview release. Windows demo binary published on GitHub Releases.

### Added
- Release workflow: pushing a `vX.Y.Z` tag builds, tests and publishes a GitHub Release with the Windows demo, SHA-256 checksums and the dependency manifest (`docs/releasing.md`).
- Render module: backend-neutral `Renderer` with a Vulkan 1.3 backend (dynamic rendering, synchronization2, swapchain with resize/minimise handling, depth buffer, validation-layer support) and a headless mode with pixel readback. Camera/projection math and cube mesh. 8 tests, including GPU tests that check rendered pixels. ADR 0009.
- `samples/spinning_cubes`: windowed demo combining ECS, systems, scene hierarchy and rendering. CI publishes a Windows build as an artifact and smoke-tests the Linux build under a virtual display.
- Vendored dependencies: Vulkan-Headers 1.4.304, volk 1.4.304, GLFW 3.4 (samples only), pinned in `third_party/dependencies.json`.
- `tools/compile_shaders.py` with a CI freshness check; test harness `AETHER_SKIP` with `AETHER_TEST_NO_SKIP=1` to forbid skips in CI.
- World: scene hierarchy (`Parent`/`Children` with consistent two-way links, cycle rejection, `destroy_recursive`, `validate`), `Transform`/`GlobalTransform` and parallel `propagate_transforms`. 9 tests including a randomized forest checked against brute-force matrices and a 100,000-deep chain. ADR 0008.
- World: `get<T>(entity, ComponentId)` fast path for hot loops.
- Foundation: math library (Vec3, Quat, Mat4) with glTF-compatible conventions. 5 tests.
- World module: archetype ECS with generational handles, UUID entity identity, named components, `each`/`par_each`/`count` queries, `CommandBuffer`, and a `Schedule` that runs systems with non-conflicting declared access in parallel. 21 tests including a randomized differential test against a reference model. ADR 0007.
- Foundation: `Uuid` (v4 generation, parsing, formatting). 4 tests.
- World micro-benchmarks.
- Project governance: Apache-2.0 licence, DCO contribution process, code of conduct, security policy, governance model, roadmap.
- CMake build with module layering checks; presets for Linux (GCC/Clang/ASan/TSan) and Windows (MSVC).
- CI on GCC, Clang, MSVC with sanitizers, ACP schema validation and DCO checks.
- Foundation module: `Result`/`Error`, assertions, platform layer, heap/arena/frame/pool allocators, work-stealing job system, structured logging, Chrome-trace tracing, fixed timestep, lifecycle state machine. 32 unit tests.
- Foundation micro-benchmarks.
- Aether Control Protocol draft 0.1 (message, tool descriptor and changeset schemas, examples, validator).
- Architecture overview, ADRs 0001–0006, RFC template, build guide.
