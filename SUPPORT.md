# Support

- **Questions and ideas:** GitHub Discussions (or an issue labelled `question` until Discussions is enabled).
- **Bugs:** open an issue with the bug report template.
- **Security issues:** follow [SECURITY.md](SECURITY.md). Never post them publicly.
- **Building from source:** [docs/building.md](docs/building.md).

The project is volunteer-run and has no paid support. There is no commercial edition with extra features.
