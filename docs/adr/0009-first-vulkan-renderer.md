# 0009. First Vulkan renderer and vendored dependencies

- **Status:** Accepted
- **Date:** 2026-11-09

## Context
The project needs a runnable windowed program to validate the engine end to end. ADR 0005 chose Vulkan first. The engine must also build offline, keep Vulkan out of its public API (for the later Metal backend), and be testable in CI machines without GPUs.

## Decision
- **Public API without Vulkan types.** `aether::render::Renderer` is an abstract interface; the window system passes a surface-creation callback that receives and returns opaque handles.
- **Vulkan 1.3, dynamic rendering, synchronization2.** No render-pass objects; two frames in flight; one render-finished semaphore per swapchain image.
- **volk** loads Vulkan at run time, so building needs only headers and a machine without a driver gets a clear error instead of a crash at load time.
- **Vendored, trimmed, pinned dependencies** (Vulkan-Headers, volk, GLFW) in `third_party/`, recorded with commit or SHA-256 in `dependencies.json`. Builds need no network.
- **GLFW for samples only.** The engine library has no windowing dependency.
- **Shaders compiled ahead of time.** SPIR-V is generated by `tools/compile_shaders.py` and committed; CI checks it matches the GLSL.
- **Headless mode with pixel readback.** GPU tests render offscreen on Mesa's software Vulkan (lavapipe) in CI and compare real pixel values, with validation layers enabled.

## Consequences
- The Windows sample builds in CI and is published as a downloadable artifact; running it needs a Vulkan 1.3 driver.
- This is a first slice: host-visible buffers, one pipeline, one light. A render graph, memory allocator, materials and GPU-driven culling come later and will replace parts of this backend.
- Committed SPIR-V must be regenerated when shaders change (enforced by CI).
- Sanitizer reports that originate inside the uninstrumented Mesa driver are suppressed for render tests only.

## Alternatives considered
- **SDL3 instead of GLFW:** more features (audio, gamepads) but much larger; can be added later for the editor or runtime.
- **FetchContent at configure time:** breaks offline builds.
- **Linking the Vulkan SDK loader:** requires the SDK on every build machine.
- **Runtime shader compilation (shaderc):** large dependency for two shaders.
