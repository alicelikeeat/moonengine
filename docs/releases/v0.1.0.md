**First preview of Aether Engine** — an open source (Apache-2.0), AI-native 3D game engine in early development.

This release contains a runnable Windows demo built entirely from this repository by GitHub Actions. It is a technology preview, not a usable game engine yet.

## Download and run

1. Download `aether-engine-v0.1.0-windows-x64.zip` below and unzip it.
2. Double-click `aether_spinning_cubes.exe`. Press **Esc** to quit.

You need a GPU driver with **Vulkan 1.3** (NVIDIA, AMD and Intel drivers from 2022 onward). The window title shows the GPU in use and the frame rate. Options: `--validation`, `--no-vsync`, `--frames N`.

Windows may warn that the program is from an unknown publisher: release binaries are not code-signed yet. Verify the download with `SHA256SUMS.txt`, or build it yourself from the tagged source.

## What's inside

- **Foundation:** allocators, work-stealing job system, structured logging, Chrome-trace profiling, fixed timestep, lifecycle, UUIDs, math.
- **World:** archetype ECS with UUID identity, queries, command buffers, a parallel system scheduler, scene hierarchy and transform propagation.
- **Render:** Vulkan 1.3 renderer (dynamic rendering, swapchain, depth), headless mode with pixel-checked tests.
- **Aether Control Protocol 0.1 (draft):** JSON Schemas for the tool and AI-agent protocol.
- **Demo:** a solar system of cubes driven by ECS systems and the scene hierarchy.

79 automated tests run on GCC, Clang and MSVC, under AddressSanitizer and ThreadSanitizer, with GPU tests on a software Vulkan device. See [CHANGELOG.md](https://github.com/alicelikeeat/moonengine/blob/v0.1.0/CHANGELOG.md) for details.

## Known limitations

- First real-GPU runs happen with this release; the renderer was verified on software Vulkan (Mesa lavapipe) in CI.
- One light, flat colours: no textures, materials or shadows yet. No editor, no saving scenes, no AI agents yet.
- Binaries are unsigned. An SBOM is provided as the dependency manifest (`*-dependencies.json`); signed releases are planned (see ROADMAP).
