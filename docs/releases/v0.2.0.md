**Aether Editor preview** — the first version of the level editor, plus the runtime demo.

Built entirely from this repository by GitHub Actions. This is an early preview: it edits a level in memory but cannot save levels yet.

## Download and run

1. Download `aether-engine-v0.2.0-windows-x64.zip` below and unzip it.
2. Run `aether_editor.exe` for the editor, or `aether_spinning_cubes.exe` for the runtime demo.

Requires a GPU driver with **Vulkan 1.3**. Windows may warn about an unknown publisher (binaries are not code-signed yet); verify with `SHA256SUMS.txt`. The included `README.md` lists every panel and control.

## Editor

- Dockable, tabbed layout: **Viewport**, **Outliner**, **Details**, **Place Actors**, **Output Log**, **Stats**; menus, toolbar and status bar.
- **Viewport:** perspective view with anti-aliased ground grid and axes, click selection with highlight, **move / rotate / scale gizmos** (world or local, with snapping), fly/orbit/pan/zoom camera, focus on selection.
- **Outliner:** scene tree, search, drag-and-drop to attach/detach (world position preserved), context menu.
- **Details:** rename, Location / Rotation / Scale, mesh colour, Spin component, add/remove components, copy entity ID.
- **Undo / Redo** for every edit, create, delete, duplicate and attach.
- **Play / Pause / Stop** with the level restored on Stop.

## Engine changes since 0.1.0

- Renderer UI mode: scene rendered into a viewport texture with correct sRGB handling, selection highlight, analytic ground grid.
- Math: matrix inverse, TRS decomposition, Euler angles. World: `Name` component.
- 95 automated tests on GCC, Clang and MSVC, under AddressSanitizer and ThreadSanitizer, with GPU pixel tests on software Vulkan; CI smoke-tests both applications on a virtual display with Vulkan validation.

## Known limitations

- No saving or loading of levels yet; only cubes as meshes; one light, no materials or shadows.
- Verified on software Vulkan in CI; please report how it runs on your GPU.
