**Save and open levels** — the editor now keeps your work, and the runtime plays what you build.

Built entirely from this repository by GitHub Actions. Early preview.

## Download and run

1. Download `aether-engine-v0.3.0-windows-x64.zip` below and unzip it.
2. Run `aether_editor.exe`. Build something, then **File > Save** (Ctrl+S).
3. Play your level without the editor: `aether_spinning_cubes.exe --level MyLevel.alevel`.

Requires a GPU driver with **Vulkan 1.3**. Binaries are not code-signed yet; verify with `SHA256SUMS.txt`.

## New

- **Level files** (`.alevel`): readable JSON, documented in `docs/formats/level-v1.md`, with a public schema. Diff-friendly (stable ordering, short numbers) and safe to open from untrusted sources: bad files are rejected without touching the open level.
- **Forward compatible:** data from components this version does not know (newer engines, plug-ins) is kept and written back, never silently dropped. Files from newer format versions are refused with a clear message.
- **Editor:** New, Open, Open Recent, Save, Save As, a built-in file browser, unsaved-changes prompt (including on window close), `*` in the title, open by drag-and-drop or command line.
- **Runtime:** `--level` runs any level saved by the editor, with the same components and systems (new Gameplay module).
- The demo level ships as `levels/solar_system.alevel`.

## Quality

- New: JSON parser fuzzing (20,000 mutated inputs), level-load fuzzing (3,000 mutated files, all rejected cleanly or loaded consistently), exact float round-trips, migration chain tests, schema/engine consistency test.
- 118 automated tests on GCC, Clang and MSVC, under AddressSanitizer and ThreadSanitizer; CI runs the editor and the runtime (including the sample level) on a virtual display with Vulkan validation.

## Known limitations

- Only cube meshes; one light; no materials, textures or shadows yet. No multi-select. Verified on software Vulkan in CI.
