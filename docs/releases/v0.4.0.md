**Real 3D models** — import glTF files, browse them in a Content Browser, and drag them into your level. Meshes now support textures.

Built entirely from this repository by GitHub Actions. Early preview.

## Download and run

1. Download `aether-engine-v0.4.0-windows-x64.zip` below and unzip it.
2. Run `aether_editor.exe`. The **Content Browser** (bottom panel) lists the sample models in `Content\`: drag one into the viewport, or double-click it.
3. Add your own: copy `.glb` / `.gltf` files (Blender: *File > Export > glTF 2.0*) into `Content\` and press **Refresh**.
4. Open `levels\model_garden.alevel` for a small scene made from the sample models, or play it with `aether_spinning_cubes.exe --level levels\model_garden.alevel`.

Requires a GPU driver with **Vulkan 1.3**. Binaries are not code-signed yet; verify with `SHA256SUMS.txt`.

## New

- **glTF 2.0 import** (`.gltf`, `.glb`): meshes, node hierarchy, base colour and PNG/JPEG base colour textures. Each model node becomes an actor you can select, move and re-parent in the Outliner.
- **Content Browser:** filter, refresh, double-click to add at the view focus, drag into the viewport to place on the ground. Every placement is one undo step.
- **Textures** with mipmaps; Details shows each actor's mesh and texture.
- **Levels remember models** by their path in the content folder and load them when opened, in the editor and in the runtime. Older levels open unchanged.
- **Safe with downloaded files:** the importer checks every offset, index and size, refuses paths that leave the model's folder, and was fuzz-tested with 3,000 corrupted files.
- Sample models (crate, torus, tree) are generated from code and ship under Apache-2.0.

## Quality

- 130 automated tests on GCC, Clang and MSVC, under AddressSanitizer and ThreadSanitizer, including pixel checks of textured rendering and model loading on software Vulkan. CI runs the editor and the runtime with the model level and fails on any warning.

## Known limitations

- Base colour only: no metallic/roughness, normal maps, animation or skinning yet (skipped with a note in the Output Log). One light, no shadows.
- Content Browser tiles show the file type, not a rendered thumbnail.
- Levels refer to models by path and mesh index; renaming a model file or re-exporting it with a different mesh order changes what the level shows. An asset database with stable IDs is planned.
